Details

2 var() reference(s) have no fallback value

where: (inline): var(--ds-color-text) at styles.css:8; (inline): var(--ds-space-4) at styles.css:10

risk: If the token is ever undefined — wrong import order, a consumer that never loaded the token file — the property resolves to nothing and the element renders unstyled.

fix: Add a fallback: var(--token, <value>) — the base-theme value, so a missing token degrades to something sane instead of nothing.
