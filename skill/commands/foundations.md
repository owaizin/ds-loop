## Evidence first

Before replying, read the repository instructions and the code in your target project.
Read the current scales, themes and representative product consumers.
Run `ds-loop context .`, then `ds-loop audit . --json` there, unfiltered.
Keep coverage and `not-checked` results with the findings.
Run `ds-loop scan .` and `ds-loop sweep .` for the palette evidence.
If this is a workspace, also run `ds-loop consumers . --json`.

## Route

Follow [foundations](../reference/foundations.md), [tokenize](../reference/tokenize.md),
and the [foundations](../roles/foundations.md) role.

## Finish line

You have real options compared in product context and a recorded choice or open
decision. Your team owns brand and shared token choices; implement only agreed scope.
